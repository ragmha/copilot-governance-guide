## Release status and scope

- Enterprise-team model access: **public preview - use with caution**. Switching changes granular model-control mode.
- Custom MCP registry: **public preview - use with caution**. Managed-settings allowlists are generally available on supported clients.
- Agent session audit streaming: **public preview - use with caution**, limited to the enterprise types in the monitoring guide.
- Other capability support varies by plan, client and surface. Absence of a preview tag here is not a guarantee of availability or approval.
